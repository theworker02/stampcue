# stampcue

Stamp config/cue key checks for twelve-factor services.

**Site:** https://theworker02.github.io/stampcue/

## Install / run

```bash
git clone https://github.com/theworker02/stampcue.git
cd stampcue
node src/cli.js
node --test
```
